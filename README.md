# ステラペットマルシェ ARフィルター

スマートフォンで開くとミッション案内が表示され、ボタンを押すとカメラを起動します。透過フレームを重ねて撮影し、撮影画像を端末へ保存できます。

## GitHub Pagesで公開する

1. `index.html` と `assets/stellar-ar-frame.png` をGitHubリポジトリに追加します。
2. リポジトリの **Settings → Pages** を開き、公開元に `Deploy from a branch`、ブランチに `main`、フォルダーに `/ (root)` を選びます。
3. 表示されたPagesのURLをスマートフォンで開きます。

カメラを使うにはHTTPSでの公開と、ブラウザーでのカメラ許可が必要です。撮影した写真はページ内で合成して端末へ保存します。Instagramへの投稿は、保存後にInstagramアプリから行ってください。

## 投稿案内のアカウント名

画面では公式アカウント表記として `@stellar_petmarche` を使っています。
