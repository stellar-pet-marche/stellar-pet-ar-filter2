# ステラペットマルシェ ARフィルター

この `index.html` はフレーム画像を内部に含む単一ファイルです。画像フォルダーの追加やパス設定が不要なので、GitHub Pagesでフレームが読み込めなくなる問題を避けられます。

## GitHub Pagesで表示する手順

1. GitHubリポジトリのトップ階層に `index.html` をアップロードします。
2. **Settings → Pages** を開き、`Deploy from a branch`、ブランチ `main`、フォルダー `/ (root)` を選んで保存します。
3. Pagesに表示されたURLをスマートフォンで開きます。GitHubのコード表示画面ではなく、PagesのURLで開いてください。
4. 最初の案内にある「ARフィルターを起動する」を押し、ブラウザーのカメラ使用を許可します。

PagesのURLはHTTPSなのでスマートフォンのカメラを利用できます。撮影した写真は端末に保存し、Instagramアプリから投稿してください。

画面のアカウント表記は `@stellar_petmarche` です。
